# 架构取舍矩阵

| 能力/模块 | 首期决策 | 原生参考 | 验收证据 |
|---|---|---|---|
| CRoutine/上下文 | 保留并对齐 | `cyber/croutine` | 状态、切换、退出测试 |
| Scheduler/Processor | 保留并对齐 | `cyber/scheduler` | Classic 调度与并发测试 |
| Classic 策略 | 保留 | `scheduler/policy/scheduler_classic` | 策略行为测试 |
| Choreography 策略 | 保留 | `scheduler/policy/scheduler_choreography` | DAG 依赖唤醒测试 |
| Node/Reader/Writer | 保留并对齐 | `cyber/node` | API 与端到端样例 |
| INTRA 传输 | 保留 | `cyber/transport` | 同进程发布订阅、延迟基准 |
| SHM 传输 | 保留 | `cyber/transport` | 双进程链路、清理测试 |
| Component/DAG/mainboard | 保留并对齐 | `cyber/component`, `mainboard` | 动态加载与失败回滚 |
| 本地拓扑发现 | 保留最小集合 | `cyber/service_discovery` | 路由选择测试 |
| RTPS/跨机 | 删除/不实现 | 原版 transport 扩展 | README 不宣传、无代码入口 |
| 监控运维、参数、record | 删除/不实现 | 原版外围模块 | 依赖与目录审计 |
| Python API | 删除/不实现 | `cyber_py3` | 构建不引入 Python |
| 根级旧 Sylar 文件 | 删除 | 非 CyberRT 架构 | CMake 与源码无引用 |
| AtomicHashMap 等自研优化 | 仅在原版职责兼容时保留 | 对照原版逐项判断 | 取舍记录与测试 |

取舍优先级：原生职责一致性 > 可验证性 > 性能优化；任何新增抽象必须有对应原版职责或明确验收用例。
